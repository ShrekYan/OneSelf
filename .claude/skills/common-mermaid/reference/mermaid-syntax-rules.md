# Mermaid 语法规范

本文档定义生成 Mermaid 图表时必须遵守的语法规则。

## 1. Subgraph 规则

- **subgraph 名称包含空格时必须用双引号包裹**
- 错误：`subgraph 应用层 - 单进程`
- 正确：`subgraph "应用层 - 单进程"`

## 2. 节点文字规则

- 节点文字**不能包含** `{ } ( ) < >` 这些特殊字符
- 遇到需要分隔的地方用 `-` 代替
- 错误：`user:full:{username}`
- 正确：`user-full-username`

## 3. 箭头标签规则

- **箭头标签不能包含中文**，部分解析器会报错
- 使用英文简写：`hit` 表示命中，`miss` 表示未命中，`query` 表示查询
- **箭头必须每个连接单独一行**
- 错误：

  ```mermaid
  L1--hit-->回填L1 密码验证CPU
  ```

- 正确：

  ```mermaid
  L1--hit-->回填L1
  回填L1-->密码验证CPU
  ```

## 4. 换行规则

- 每个箭头连接单独一行
- 不要在一行放多个连接
- 使用 `<br/>` 或 `\n` 在节点内换行，语法：`节点名[文字<br/>换行]`

## 5. 反引号规则

- mermaid 代码块整体用三个反引号包裹
- **节点内部不要使用反引号**
