# 综合报告输出规范

## 报告结构

```markdown
# 前端综合审查报告

## 审查概览

- 检查范围：
- 审查维度：代码质量、安全、性能
- 问题总数：
- 严重问题数：

## 问题汇总（按优先级）

### 严重

### 高

### 中

### 低

## 按文件 / 模块分布

## 修复建议

## 下一步行动
```

## 优先级定义

| 优先级 | 含义 | 处理建议 |
|--------|------|----------|
| 严重 | 可能导致线上故障、安全漏洞或数据泄露 | 必须立即修复 |
| 高 | 明显违反规范或存在较大风险 | 在本次迭代内修复 |
| 中 | 影响可维护性或存在潜在风险 | 安排后续修复 |
| 低 | 建议优化项 | 视情况处理 |

## `--only-issues` 模式

当用户指定 `--only-issues` 时，报告应省略以下部分：

- 无问题文件 / 模块的详细说明。
- 对每个 Agent 的检查方法描述。
- 冗余的正面评价。

保留内容：

- 问题清单。
- 问题位置。
- 优先级。
- 修复建议。
- 下一步行动。
