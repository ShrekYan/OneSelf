# Figma 转换检查清单

本文档提供 Figma 设计稿转代码的完整检查清单，确保转换质量符合项目规范。

## 前置检查（执行前）

### 信息完整性
- [ ] Figma URL 或 fileKey/nodeId 已提供
- [ ] 产出物类型已明确（页面/组件/修改）
- [ ] 产出物目标路径已确认
- [ ] 是否涉及新接口已评估

### 工具可用性
- [ ] Figma MCP 工具可正常调用
- [ ] 能够成功获取 Figma 设计上下文
- [ ] 设计稿节点可访问（权限检查）

## 设计稿解析检查

### 结构提取
- [ ] 正确识别了 Figma 节点层级关系
- [ ] 正确识别了节点类型（Frame/Component/Instance/Text/Vector）
- [ ] 提取了所有必要的子节点信息
- [ ] 识别了组件变体（如有）

### 样式提取
- [ ] 提取了布局方式（Auto Layout / 绝对定位）
- [ ] 提取了尺寸（width / height）
- [ ] 提取了间距（padding / margin / gap）
- [ ] 提取了颜色（fills / strokes）
- [ ] 提取了圆角（borderRadius）
- [ ] 提取了阴影（effects）
- [ ] 提取了文本样式（fontSize / fontWeight / lineHeight）

### 资产提取
- [ ] 识别了所有图片节点
- [ ] 识别了所有图标节点（Vector）
- [ ] 检查了资产复用可能性
- [ ] 记录了需要下载的资产清单

## 代码生成检查

### 目录结构
- [ ] 页面是否按四文件结构创建（`index.tsx` + `useStore.ts` + `constant.ts` + `types.ts`）
- [ ] 组件是否按规范目录结构创建
- [ ] 文件命名是否符合 PascalCase/camelCase 规范

### 类型定义
- [ ] 是否定义了完整的 Props 接口（组件）
- [ ] 是否定义了完整的 API 请求/响应类型
- [ ] 是否定义了页面状态类型（useStore）
- [ ] 是否避免了 `any` 类型

### React 组件
- [ ] 是否使用了 `useObserver` Hook（而不是 `observer` HOC）
- [ ] 是否优先使用了 Ant Design Mobile 组件
- [ ] 是否使用了语义化 HTML 标签
- [ ] 是否正确处理了条件渲染（加载/空/错误状态）
- [ ] 是否识别并拆分了可复用组件

### MobX 状态管理
- [ ] 页面状态是否使用 `useLocalObservable`
- [ ] `useLocalObservable` 中的方法是否使用方法语法（非箭头函数）
- [ ] 是否避免了在组件内直接修改 MobX 状态
- [ ] 是否将复杂业务逻辑抽离到 hooks/

### SCSS 样式
- [ ] 是否使用了 `*.module.scss`（CSS Modules）
- [ ] 样式类名是否使用 camelCase
- [ ] 根容器 class 是否为 `{componentName}Container`
- [ ] 是否使用了项目变量（`$primary-color` 等）而不是硬编码
- [ ] 是否遵循了 8px 网格间距系统
- [ ] 是否基于 750px 设计稿使用 px 单位
- [ ] 是否添加了 `:active` 点击反馈（可点击元素）

### 设计 Token 映射
- [ ] 颜色是否优先使用了项目变量？
- [ ] 字号是否使用了项目字体层级变量？
- [ ] 间距是否符合 8px 网格系统？
- [ ] 圆角是否使用了项目圆角变量？
- [ ] 是否有硬编码值可以用变量替代？

### 资产处理
- [ ] 是否先检查了资产复用可能性？
- [ ] 资产是否放到了正确的目录？
- [ ] 资产命名是否符合 kebab-case 规范？
- [ ] 图片是否进行了压缩优化？
- [ ] SVG 是否进行了优化？
- [ ] 资产引用路径是否使用了 `@/` 别名？
- [ ] 图片是否添加了 `alt` 属性？

### 布局转换
- [ ] Auto Layout 是否正确转换为 Flexbox？
- [ ] 间距（gap/padding/margin）是否符合设计稿？
- [ ] 对齐方式是否正确？
- [ ] 是否避免了不必要的绝对定位？
- [ ] 布局是否响应式？

### API 对接
- [ ] API 是否定义在 `apps/web/src/api/` 目录
- [ ] 是否定义了完整的请求/响应类型
- [ ] 是否使用了项目的 axios 封装实例
- [ ] 是否正确处理了错误情况

## 规范符合性检查

### 导入路径
- [ ] 是否只使用了 `@/` 别名，没有相对路径（`../../`）
- [ ] 导入顺序是否正确（官方库 → 第三方包 → 内部模块 → 相对路径）

### 代码格式
- [ ] 字符串是否使用单引号
- [ ] 语句末尾是否有分号
- [ ] 对象/数组末尾是否有 trailing comma
- [ ] 文件末尾是否保留了空行
- [ ] 缩进是否使用 2 个空格

### 可访问性
- [ ] 图片是否有 `alt` 属性
- [ ] 可点击元素是否使用 `<button>` 或 `<a>`（而不是 `<div onClick>`）
- [ ] 可点击元素尺寸是否 ≥ 44px（设计稿 ≥ 88px）
- [ ] 是否添加了必要的 `aria-label`

### 安全规范
- [ ] 是否没有存储 Token 到 localStorage/sessionStorage
- [ ] 是否没有手动设置 Authorization 请求头
- [ ] 是否没有在代码中硬编码敏感信息

## 功能完整性检查

### 交互行为
- [ ] 点击交互是否完整实现
- [ ] 表单提交是否完整实现
- [ ] 状态切换是否完整实现（如点赞/收藏）
- [ ] 页面跳转是否完整实现

### 边界情况
- [ ] 空数据状态是否有兜底展示
- [ ] 加载中状态是否有 Loading 提示
- [ ] 加载失败状态是否有错误提示和重试按钮
- [ ] 数据越界是否有处理（如文本过长截断）

## 交付检查

### 代码质量
- [ ] 是否执行了 `npm run lint` 且通过
- [ ] 是否执行了 `npx tsc --noEmit` 且通过
- [ ] 是否移除了所有调试用的 `console.log`
- [ ] 是否添加了必要的代码注释

### 文档说明
- [ ] 是否说明了 Figma 节点映射关系
- [ ] 是否说明了涉及的新接口（如有）
- [ ] 是否说明了需要上传的静态资产（如有）
- [ ] 是否说明了特殊实现细节

### 测试验证
- [ ] 是否手动验证了页面/组件渲染正确
- [ ] 是否验证了交互行为符合预期
- [ ] 是否验证了响应式布局正常
- [ ] 是否验证了边界情况处理正常

## 最终确认

- [ ] 所有检查项已通过
- [ ] 代码已提交到 Git（如适用）
- [ ] 已通知用户转换完成
- [ ] 已列出待用户确认的事项（如有）
