# 报告模板

## 性能分析报告模板

```markdown
## 性能分析报告：`{页面/模块名称}`

### 结论摘要
{整体结论、最关键问题、优先处理建议}

### 分析范围
- 分析对象: {页面/组件/模块}
- 分析目标: {首屏/交互/内存/网络/综合}
- 技术栈: React 19 + MobX + Vite + Ant Design Mobile
- 数据可信度: 高/中/低

### P0/P1 问题列表

#### P0 - {问题标题}
- **位置**: `src/pages/xxx/index.tsx:{行号}`
- **证据**: {代码/配置/构建产物证据}
- **影响**: {对用户体验、指标的影响}
- **优化建议**:
  ```tsx
  // 优化前
  {code}

  // 优化后
  {code}
  ```
- **预期收益**: {量化收益}
- **风险**: {低/中/高}
- **验证方式**: {对比方法}

### 潜在风险
{缺少充分证据但值得关注的问题}

### 需要补充的数据
- [ ] Lighthouse 报告
- [ ] Performance Trace
- [ ] 真机弱网测试结果

### 最终建议
1. 先处理 P0 问题
2. 再处理 P1 问题
3. P2/P3 问题列入迭代计划
```
