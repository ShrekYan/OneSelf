# 性能问题分类

| 类别 | 常见症状 |
|------|----------|
| **加载性能** | 白屏时间长、首屏加载慢、资源体积大 |
| **交互性能** | 滚动卡顿、点击响应慢、动画掉帧 |
| **内存性能** | 随着使用变慢、页面后退不释放、泄漏 |
| **网络性能** | 请求过多、重复请求、缓存无效 |

## Core Web Vitals 分析

| 指标 | 移动端 H5 目标 | 潜在成因 |
|------|----------------|----------|
| **LCP** ( Largest Contentful Paint ) < 2.5s | 首屏最大内容渲染时间 | 关键资源阻塞、图片未优化、主线程繁忙 |
| **INP** ( Interaction to Next Paint ) < 100ms | 交互响应延迟 | 事件处理慢、长任务阻塞、重渲染扩散 |
| **CLS** ( Cumulative Layout Shift ) < 0.1 | 布局偏移量 | 图片无尺寸、动态内容插入、字体加载闪烁 |

**辅助指标**: FCP < 1.8s | TTFB < 800ms | TTI < 3.8s | Long Task < 50ms

## 分析工作流

```
1. 明确范围 → 确定分析对象、目标、技术栈
   ↓
2. 收集证据 → 读取代码、搜索模式、分析构建产物
   ↓
3. 分类判断 → 确定问题 / 高可信风险 / 潜在风险 / 非问题
   ↓
4. 优先级评估 → P0/P1/P2/P3 分级
   ↓
5. 输出报告 → 包含证据、影响、建议、验证方式
   ↓
6. 落地优化 → 用户确认后执行
```
