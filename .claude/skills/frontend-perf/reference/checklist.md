# 检查清单（按优先级）

## 🔴 高优先级 - 严重影响用户体验

### 1. React 重渲染问题
- [ ] 是否存在对象/函数字面量直接传入 props 导致每次重渲染？
- [ ] `observer` 是否包裹在正确位置，避免过度订阅？
- [ ] 大组件是否未拆分，状态变化导致整棵树重渲染？
- [ ] 列表渲染是否使用了不稳定的 `key`（如 `index`、随机值）？
- [ ] 是否在 render 中进行昂贵计算？

### 2. MobX 状态优化
- [ ] 状态粒度是否合理？是否把不相关的字段放在同一个可观察对象中？
- [ ] 计算属性是否使用 `computed` 缓存派生数据？
- [ ] 页面退出后状态是否清理？
- [ ] 是否在 mobx reaction 中正确清理？

### 3. 长列表性能
- [ ] 列表超过 50 项是否使用虚拟滚动？
- [ ] 是否一次性渲染所有数据？
- [ ] 是否分页/无限滚动加载？
- [ ] 列表项组件是否被 `observer` 正确包裹？

### 4. 图片资源优化
- [ ] 非首屏图片是否懒加载？
- [ ] 大图是否压缩？是否使用 WebP 格式？
- [ ] 图片是否设置了宽高比，避免 CLS 布局偏移？
- [ ] 是否有大图小用（用 2x 图展示在 1x 屏幕）？
- [ ] LCP 图片是否未懒加载且优先级高？

### 5. 内存泄漏
- [ ] `setInterval`/`setTimeout` 是否在 `useEffect` cleanup 中清除？
- [ ] `addEventListener` 是否移除？
- [ ] 全局缓存/Map 是否无限制增长？
- [ ] 路由缓存是否缓存了过多页面？
- [ ] MobX reaction 是否在组件卸载时清理？

## 🟠 中优先级 - 影响性能体验

### 加载性能
- [ ] 路由是否配置懒加载？
- [ ] 非首屏组件是否按需加载？
- [ ] 是否有大同步脚本阻塞首屏？
- [ ] 关键资源是否使用 `preload`/`prefetch`？
- [ ] 字体加载是否优化（`font-display: swap`）？

### 网络请求
- [ ] 不常变数据是否启用 API 缓存（`cache: true`）？
- [ ] 是否有重复并发请求（检查 `cancel-manager` 配置）？
- [ ] 是否可以合并多个小请求？
- [ ] 是否需要时才请求，而非预加载过多数据？
- [ ] 首屏 API 是否串行？是否可以并行？

### 打包体积
- [ ] 是否整体引入大库（如 `react-use`、`lodash`）而不是按需引入？
- [ ] 是否引入了未使用的第三方依赖？
- [ ] Ant Design Mobile 是否按需加载？
- [ ] 是否有重复依赖未去重？

### 样式性能
- [ ] SCSS 嵌套是否超过 3 层？
- [ ] 是否过度使用昂贵 CSS 属性（`box-shadow`、`filter`）？
- [ ] 动画是否优先使用 `transform`、`opacity`？
- [ ] 是否频繁触发强制同步布局（读写布局属性）？

### 移动端交互
- [ ] 频繁触发的事件（scroll、input、resize）是否防抖节流？
- [ ] 可点击区域是否 ≥ 44px × 44px？
- [ ] 是否适配安全区域（刘海屏、圆角屏）？
- [ ] 是否禁用了 300ms 点击延迟（`touch-action: manipulation`）？

## 🟡 低优先级 - 进一步优化

- [ ] 是否利用 React 19 特性（`useTransition`、`useDeferredValue`）处理非紧急更新？
- [ ] 大量数据计算是否放到 Web Worker？
- [ ] 第三方脚本是否异步加载？
- [ ] 是否存在重复代码未提取公共模块？
