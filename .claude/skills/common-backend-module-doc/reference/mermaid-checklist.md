# mermaid 图语法检查规则

> 本文件定义 mermaid 图的语法检查规则，用于验证生成的图表是否正确。

---

## 架构图检查项

- [ ] 使用 `flowchart TD` 方向
- [ ] 每个分层有明确的 `subgraph` 定义
- [ ] 使用 `classDef` 定义颜色样式
- [ ] 所有节点都有正确的类引用（如 `:::controller`）
- [ ] 箭头方向正确，表示调用关系
- [ ] 节点标签清晰，包含层级说明

## 序列图检查项

- [ ] 使用 `sequenceDiagram`
- [ ] 参与者按调用顺序排列
- [ ] 使用 `->>` 和 `-->>` 区分同步和异步调用
- [ ] 使用 `alt` 分支处理不同情况
- [ ] 流程完整，从客户端请求到响应返回

## ER 图检查项

- [ ] 使用 `erDiagram`
- [ ] 表关系使用正确的符号（`||--o{`、`||--||`、`o{--o{`）
- [ ] 表名使用下划线命名
- [ ] 关系描述清晰

## 通用检查项

- [ ] 图表能在 mermaid.live 中正确渲染
- [ ] 没有语法错误
- [ ] 图表简洁明了，不包含无关信息
