# 文档生成最终检查规则

> 本文件定义文档生成完成后的最终检查规则。

---

## 章节完整性检查

- [ ] 文档信息表格完整（生成日期、模块路径、项目版本、代码分支）
- [ ] 模块概述包含职责、位置、依赖关系
- [ ] 架构设计包含 mermaid 架构分层图
- [ ] 核心流程包含 mermaid 序列图
- [ ] 技术选型对比表格完整，包含决策理由
- [ ] 具体方案详述包含目录结构、组件职责、设计决策
- [ ] 数据库设计包含涉及表、索引设计、性能优化
- [ ] API 接口概览表格完整
- [ ] 测试策略包含单元测试和集成测试说明
- [ ] 已知问题和后续优化列表完整

## 内容质量检查

- [ ] 技术选型决策有明确理由
- [ ] 数据库索引设计有明确用途说明
- [ ] mermaid 图语法正确，能正常渲染
- [ ] 文档语言专业、清晰
- [ ] 没有语法错误和拼写错误

## 格式规范检查

- [ ] 文件命名符合规范（`{module-name}-YYYYMMDD.md`）
- [ ] 输出路径正确（`docs/services/backend/`）
- [ ] 章节编号正确
- [ ] 表格格式正确
- [ ] 代码块有正确的语言标识

## 决策可见性检查

- [ ] 每个设计决策都说明了"为什么"
- [ ] 放弃的方案也有说明
- [ ] 关键技术选型点都有对比
