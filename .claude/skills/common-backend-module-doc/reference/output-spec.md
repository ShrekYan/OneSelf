# 输出位置和执行流程

> 本文件定义文档输出路径格式和完整执行流程。

---

## 输出路径格式

文档输出到项目根目录下的 `docs/services/backend/` 目录：

```
docs/services/backend/{module-name}-YYYYMMDD.md
```

- `{module-name}`：模块名称，从模块路径中提取
- `YYYYMMDD`：生成日期，格式为年月日

## 完整执行流程

1. **参数解析**：解析用户输入的模块路径
2. **路径验证**：检查模块路径是否存在，是否为有效的 NestJS 模块目录
3. **代码探索**：
   - 读取模块目录结构
   - 读取 Controller、Service、Repository 源码
   - 读取模块定义文件（`*.module.ts`）
   - 读取 DTO 和实体定义
4. **信息提取**：
   - 提取模块职责和边界
   - 提取技术选型决策点
   - 提取数据库表和索引设计
   - 提取 API 接口定义
5. **文档生成**：按章节顺序读取 reference 文件，填充内容
6. **图表生成**：根据代码分析结果生成 mermaid 架构图和流程图
7. **文件写入**：将生成的文档写入指定路径
8. **结果验证**：读取 final-checklist.md 进行最终检查
9. **结果反馈**：向用户输出生成的文件路径和摘要

## 文件命名规范

- 使用小写字母和连字符
- 不使用空格或特殊字符
- 日期格式为 `YYYYMMDD`（如 20240115）
