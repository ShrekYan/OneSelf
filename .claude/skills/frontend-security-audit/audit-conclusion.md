# Audit Conclusion Criteria

## 通过

满足：

- 无高危问题。
- 中危问题可接受或已有明确补偿措施。
- 不存在明显敏感信息泄露。
- 不存在认证、授权、隐私、数据完整性等核心业务阻断风险。

## 有条件通过

满足：

- 无直接可利用高危问题。
- 存在中低危问题。
- 修复建议明确。
- 风险在业务可接受范围内，或已有临时补偿措施。

## 不建议通过

满足任一条件：

- 存在高危 XSS。
- 存在敏感信息泄露。
- 存在认证授权绕过。
- 存在关键业务参数可篡改。
- 存在账号安全、权限变更、资源删除、数据导出等敏感操作风险。
- 存在无法评估但影响范围较大的安全疑点。
