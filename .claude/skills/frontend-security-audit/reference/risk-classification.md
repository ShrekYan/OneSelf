# 风险分级

## 高危

满足任一条件：

- 可导致 XSS 执行。
- 可泄露 Token、Cookie、个人身份信息、联系方式、用户标识、业务敏感数据等敏感信息。
- 可越权访问或操作他人资源、订单、用户资料或业务数据。
- 可篡改关键业务参数。
- 可绕过登录、认证或授权。
- 可导致账号安全、权限变更、资源删除、数据导出等敏感操作风险。

## 中危

满足任一条件：

- 敏感信息处理不规范但未确认直接泄露。
- 本地存储存在隐私或串号风险。
- 第三方脚本缺少完整性校验或来源边界不清。
- CSP 缺失或过宽。
- 跨窗口消息缺少来源或结构校验。
- 前端权限控制存在误导性，可能造成安全边界误判。
- 错误信息、日志或埋点暴露内部实现或敏感业务上下文。

## 低危

满足任一条件：

- 日志、注释、测试代码有信息泄露倾向。
- 缺少安全响应头建议，但无法确认当前部署风险。
- 依赖存在低危漏洞或版本治理问题。
- 表单校验不完整但未直接影响敏感操作。
- 安全边界不清晰但暂未形成直接风险。
- 属于防御增强或安全基线优化建议。
