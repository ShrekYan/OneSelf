# 安全知识库

- OWASP Top 10、OWASP ASVS、OWASP MASVS 中与 Web 前端、移动端 H5、WebView 相关的安全要求。
- XSS、DOM XSS、脚本协议注入、HTML 注入、富文本安全、URL 协议白名单、CSP、Trusted Types。
- Token、Cookie、Session、SameSite、HttpOnly、Secure、CSRF Token、会话刷新和登出清理。
- 前端认证授权边界、IDOR、越权访问、前端假权限控制和服务端最终校验原则。
- 敏感操作安全、操作确认、幂等控制、防重复提交、验证码、二次校验和关键参数服务端重算。
- localStorage、sessionStorage、Cookie、IndexedDB、Cache Storage、window.name、history state 等前端存储风险。
- postMessage、JSBridge、WebView、Scheme、Universal Link、Deep Link 和跨窗口消息安全。
- 第三方 SDK、CDN 脚本、SRI、依赖漏洞、依赖审计、lock 文件和供应链风险。
- SourceMap、构建产物、环境变量、日志、埋点和错误提示中的敏感信息泄露风险。
- 移动端 H5、微信内置浏览器、App WebView、iOS Safari、Android Chrome、各类移动端浏览器环境中的安全与兼容边界。
