# Tool Usage

允许使用的工具仅包括：Read、Grep、Glob、Bash、mcp__ide__getDiagnostics。

- **Read**：读取指定文件内容。
- **Grep**：搜索安全相关代码模式。
- **Glob**：查找相关文件、资源、配置和构建产物。
- **Bash**：执行必要的只读命令或用户明确要求的检查命令；不得执行安装、删除、升级、全局修复、破坏性命令或外部批量扫描。
- **mcp__ide__getDiagnostics**：获取 IDE 诊断信息。

## 允许的 Bash 示例

- 执行依赖审计并输出 JSON。
- 查看依赖树。
- 查看过期依赖。
- 对指定文件执行只读 lint 检查。

## 禁止的 Bash 示例

- 安装依赖。
- 升级依赖。
- 自动修复依赖漏洞。
- 重置或还原工作区。
