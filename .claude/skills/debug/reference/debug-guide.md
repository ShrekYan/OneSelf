# 调试诊断指南

## 核心能力

### 错误分析

- 堆栈跟踪解读
- 运行时异常分析
- 构建错误分析
- 类型/lint 错误诊断

### 代码路径追踪

- 识别入口点
- 追踪数据流
- 追踪状态变化
- 追踪异步操作
- 识别竞态条件

### 假设测试

- 生成可能原因
- 按可能性排序
- 收集证据
- 确认或排除假设

### 环境诊断

- 依赖问题
- 配置不匹配
- 构建/运行时环境
- CI/CD 失败

### 常见 Bug 模式匹配

| Bug 模式 | 检查方向 |
|---------|---------|
| **微信白屏** | JS 语法兼容性、Promise 未 catch、资源加载失败、静态资源路径、base64 长度 |
| **金额精度丢失** | 浮点运算、`toFixed()` 使用、整数/分单位存储、BigDecimal |
| **鸿蒙兼容性** | base64 上传限制、flex 布局差异、WebView 版本差异、CSS 特性支持 |
| **页面卡顿** | 不必要重渲染、长列表未虚拟滚动、同步计算阻塞主线程、内存泄漏 |
| **样式错乱** | CSS 优先级、flex 兼容、安全区域适配、不同设备像素比 |
| **接口调用失败** | CORS 配置、鉴权 Token、请求参数格式、网络超时重试 |
| **状态不同步** | MobX 可观察性、响应式依赖、异步竞态条件 |

### 代码变更影响分析

**输入**：Git 提交范围、文件列表

**分析维度**：

- **前端**：组件 Props 变更、Store 状态变更、API 调用变更、样式影响范围
- **后端**：Controller 接口变更、Service 方法签名变更、DTO 字段变更、数据库查询变更

### 修复方案对比

针对同一个 Bug，提供三个层级的修复方案：

| 方案层级 | 适用场景 | 权衡 |
|---------|---------|------|
| **方案 A：快速修复** | 紧急 hotfix、生产环境问题 | 改动小、上线快，但可能引入技术债务 |
| **方案 B：彻底修复** | 常规迭代、推荐方案 | 解决根本问题，但改动范围较大 |
| **方案 C：重构优化** | 长期维护、架构升级 | 可扩展性好，但工作量大、需充分测试 |

## 知识库范围

- **前端**：`apps/web/src/`
- **后端**：`services/**/src/`
- **排除**：`node_modules/`、`dist/`、`build/`
