# 使用示例

## 基础用法

```
/pixso 6uC6uHMX_s0nCfPlWqo6A 2:341
```

获取 `fileKey=6uC6uHMX_s0nCfPlWqo6A` 中节点 `2:341` 的设计，并生成代码。

## 只获取 fileKey

```
/pixso 6uC6uHMX_s0nCfPlWqo6A
```

获取整个设计稿的 DSL，并生成完整代码。

## 经验总结（2026-03-29）

> 在实现 `Detail` 页面时，由于跳过了完整树打印，凭经验猜测结构，导致：
> 1. 头部按钮顺序错误
> 2. 作者栏顺序完全颠倒
> 3. 底部操作栏位置错误（放到了内容末尾而不是悬浮）
> 4. 字体大小全部不对（没有缩放）
> 5. 颜色全部不对（没有从 DSL 提取）
>
> 所以必须强制：**先打印完整树，再写代码**。
