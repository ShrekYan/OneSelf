# 安全审计工作流程

## 第一步：确认扫描范围

- 检查用户是否提供了需要扫描的完整文件内容
- 如果只有部分代码，明确告知需要提供完整上下文才能准确扫描

## 第二步：按风险优先级扫描

按照以下维度**从高风险到低风险**顺序扫描，不要遗漏：

1. 认证与授权（最高风险）
2. 输入验证（高风险）
3. SQL 注入防护
4. XSS 跨站脚本防护
5. CSRF 防护
6. 敏感信息泄露
7. 配置安全
8. 错误与异常处理
9. 文件上传/下载（如有）
10. 日志安全
11. 业务逻辑安全
12. 限流与防暴力破解
13. 依赖安全
14. Redis 安全（如有使用）
15. 并发安全
