# 输出要求

## 问题输出格式

对于每个发现的漏洞，按照以下结构输出：

```
### [T0/T1/T2] [风险类别] 简短标题

**问题描述**:
> 一句话清楚说明漏洞在哪里，有什么风险

**当前漏洞代码**:
```typescript
// 贴出问题代码片段
```

**修复后的正确代码**:
```typescript
// 给出完整的修复示例
```

**为什么这是安全问题**:
- 说明属于哪类安全风险（如 OWASP Top 10 中的哪一项）
- 解释被利用可能造成什么后果
- 说明修复原理
```

## 优先级定义

- **[T0]** - 严重漏洞 → **必须立即修复**。可被远程利用、可能导致敏感数据泄露、服务器被入侵。
- **[T1]** - 中等风险 → **建议尽快修复**。可能导致越权访问、信息泄露。
- **[T2]** - 低风险/改进 → **可以后续优化**。安全最佳实践改进，不直接导致漏洞。
