# 我的博客功能

## 公共组件

### 按钮组件

- 目标描述：实现通用 Button 组件，支持 primary / default / danger 三种样式
- 上下文：多个页面需要使用统一的按钮样式
- 质量标准：通过 lint 和 TypeScript 类型检查，支持 disabled 状态
- 约束条件：使用 CSS Modules，根容器 class 为 buttonContainer

### 徽章组件

- 目标描述：实现 Badge 组件，支持右上角红点显示和数字显示
- 上下文：用于消息提醒和状态标记
- 质量标准：支持数字溢出显示为 "99+"
- 约束条件：依赖 T001

## 页面层

### 用户中心页面

- 目标描述：实现用户中心页面，展示用户基本信息
- 上下文：入口在底部 Tab 的个人中心
- 质量标准：页面四文件拆分，状态逻辑放入 useStore.ts
- 约束条件：依赖 T001, T002
