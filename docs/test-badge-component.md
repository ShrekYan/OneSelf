# Badge 徽章组件开发

## 类型定义

### 定义 Badge Props 类型

- variant: dot / count / text 三种类型
- color: primary / success / warning / danger
- max: 数字最大值，超过显示 99+
- content: 文本内容

## 组件实现

### 实现 Badge 徽章核心组件

- 支持三种类型：红点 / 数字 / 文本
- 支持四种颜色主题
- 支持数字最大值
- 位置：右上角定位
