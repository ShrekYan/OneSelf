## 🌟 每日学习标准流程（严格执行）

```
1. 第一遍（30分钟）：照着图画一遍，熟悉结构
   ↓
2. 休息（10分钟）：站起来走走，不要看屏幕
   ↓
3. 第二遍（45分钟）：关掉原图默写，卡壳了先自己想 5 分钟，想不通再看答案
   ↓
4. 灵魂拷问（30分钟）：对着当天的"灵魂拷问"，每个问题认真想，写下来答案
   ↓
5. 写收获（15分钟）：今天最大的 3 个收获是什么？写下来
```

**每天总计：约 2 小时，不多不少，正好。**

### 📅 第一阶段：数据层（第 1-7 天）

**核心思想**：数据是系统的骨架，先把骨架摸透，后面的血肉才好理解

**🔥 正确学习顺序（非常重要）：**

```
第一步：先看 ER 图 → 理解设计思想（为什么要有这张表？表和表是什么关系？）
            ↓
第二步：再手敲 SQL  → 把抽象的设计，落地成具体的代码
            ↓
第三步：最后默写验证 → 关掉所有文档，凭理解重新写一遍
```

> 💡 类比：先看建筑蓝图搞懂"房子长什么样、承重墙在哪"，再动手搬砖盖房子，不要上来就瞎敲。

## 💡 学习小贴士

1. **不要赶进度**：一天的内容当天没吃透，就多花一天，宁慢勿快
2. **卡壳是好事**：卡壳的地方，正是你进步最大的地方
3. **写下来**：每天的感悟、想通的问题，随手记下来，最后你会有一本自己的"架构心法"
4. **想不通就来问我**：任何想不通的地方，随时找我讨论
