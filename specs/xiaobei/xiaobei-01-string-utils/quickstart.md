# Quickstart: 小贝字符串工具函数

## 目标

根据规格与计划，在前端工具目录中提供主字符串工具和备份字符串工具。

## 推荐实施顺序

1. 确认主字符串工具入口是否满足契约。
2. 新增或确认备份字符串工具入口。
3. 为 6 个入口补齐显式类型声明。
4. 通过契约核对确认以下场景均有明确预期，不新增单元测试：
   - 普通字符串
   - 首尾空白字符串
   - 空字符串
   - 仅空白字符字符串
   - 大小写混合字符串
   - 主入口与备份入口结果一致性
5. 在 `apps/web` 内运行类型与 lint 验证命令。

## 验证命令

```bash
cd apps/web && npm run lint
cd apps/web && npx tsc --noEmit
```

## 完成标准

- 所有契约入口存在且可导入。
- 所有入口均有明确参数与返回类型。
- 主入口和备份入口在同类转换中行为一致。
- lint 与 TypeScript 类型检查通过。
- 本阶段不要求新增或运行单元测试。
