# Stage Specification: 数组工具

**所属 Feature**: 小贝工具库 (`specs/002-xiaobei-utils`)

**Stage ID**: 03-array-utils

**Priority**: P3

## Overview

本阶段定义数组工具集合的需求规格，包含 `unique(arr)`、`sort(arr)`、`filter(arr, fn)` 三个基础数组处理能力。

## User Story

作为小贝工具库的使用者，我需要一组基础数组工具，用于完成数组去重、排序和过滤，从而减少业务代码中重复编写通用数组处理逻辑。

**Why this priority**: 数组工具是小贝工具库的第三阶段能力，适合在字符串和数字工具之后扩展工具库覆盖面，提供常见集合处理能力。

## Scope

### 包含范围

- `unique(arr)`：数组去重。
- `sort(arr)`：数组排序。
- `filter(arr, fn)`：根据过滤条件筛选数组元素。
- 数组工具需要有完整的类型声明。

### 不包含范围

- 不包含深度对象去重、自定义复杂比较器、多字段排序或异步过滤能力。
- 不包含链式集合操作、惰性求值或流式处理能力。
- 不包含对非数组集合类型的处理，例如 Map、Set、WeakMap 等。
- 不包含单元测试交付要求。

## Acceptance Scenarios

1. **Given** 使用者需要移除数组中的重复项，**When** 使用数组去重能力，**Then** 返回结果应保留唯一元素集合。
2. **Given** 使用者需要获得有序数组，**When** 使用数组排序能力，**Then** 返回结果应按照工具库定义的默认排序规则排列。
3. **Given** 使用者需要按条件筛选数组元素，**When** 使用数组过滤能力，**Then** 返回结果应仅包含满足过滤条件的元素。
4. **Given** 使用者评审数组工具质量，**When** 查看数组工具交付内容，**Then** 应能看到完整类型声明、清晰的输入输出说明和不修改输入数组的行为边界。

## Edge Cases

- 当数组为空时，数组工具需要返回可预测结果。
- 当数组包含重复元素、已排序元素、混合顺序元素时，去重和排序规则需要清晰。
- 当数组过滤条件没有匹配项时，过滤结果需要明确为空集合。

## Requirements

- **FR-006**: 数组工具集合 MUST 覆盖 `unique(arr)`、`sort(arr)`、`filter(arr, fn)` 三个能力。
- **FR-007**: 数组工具集合 MUST 明确每个能力的输入、输出和行为边界，并提供完整类型声明。

## Success Criteria

- 数组工具集合仅包含指定的 3 个能力。
- 每个工具函数都具备完整类型声明、清晰输入输出说明和明确行为边界。
- 数组工具不修改输入数组。
- 不包含单元测试交付要求。
