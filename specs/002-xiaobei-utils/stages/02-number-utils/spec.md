# Stage Specification: 数字工具

**所属 Feature**: 小贝工具库 (`specs/002-xiaobei-utils`)

**Stage ID**: 02-number-utils

**Priority**: P2

## Overview

本阶段定义数字工具集合的需求规格，包含 `add(a, b)`、`multiply(a, b)`、`formatNumber(num)` 三个基础数字处理能力。

## User Story

作为小贝工具库的使用者，我需要一组基础数字工具，用于完成常见的数值相加、相乘和数字展示格式化，从而在业务功能中复用一致的数字处理规则。

**Why this priority**: 数字工具是小贝工具库的第二阶段能力，能够补充常见数值计算与展示需求，并与字符串工具共同构成基础工具集合。

## Scope

### 包含范围

- `add(a, b)`：两个数字相加。
- `multiply(a, b)`：两个数字相乘。
- `formatNumber(num)`：格式化数字显示。
- 数字工具需要有完整的类型声明。

### 不包含范围

- 不包含复杂数学运算，例如除法、取模、幂运算、统计聚合、金融精度计算等。
- 不包含多币种、单位换算、百分比规则或本地化数字格式策略。
- 不包含任意精度数字库或大数计算能力。
- 不包含单元测试交付要求。

## Acceptance Scenarios

1. **Given** 使用者需要计算两个数字的和，**When** 使用数字相加能力，**Then** 返回结果应为两个输入数字的和。
2. **Given** 使用者需要计算两个数字的乘积，**When** 使用数字相乘能力，**Then** 返回结果应为两个输入数字的乘积。
3. **Given** 使用者需要以统一方式展示数字，**When** 使用数字格式化能力，**Then** 返回结果应符合工具库定义的数字展示格式。
4. **Given** 使用者评审数字工具质量，**When** 查看数字工具交付内容，**Then** 应能看到完整类型声明和清晰的输入、输出、行为边界说明。

## Edge Cases

- 当数字工具接收零、负数或小数时，基础计算能力需要有明确、可预测的结果。
- 当数字格式化接收普通整数、小数或较大数字时，展示格式需要保持一致。

## Requirements

- **FR-004**: 数字工具集合 MUST 覆盖 `add(a, b)`、`multiply(a, b)`、`formatNumber(num)` 三个能力。
- **FR-005**: 数字工具集合 MUST 明确每个能力的输入、输出和行为边界，并提供完整类型声明。

## Success Criteria

- 数字工具集合仅包含指定的 3 个能力。
- 每个工具函数都具备完整类型声明、清晰输入输出说明和明确行为边界。
- 不包含单元测试交付要求。
