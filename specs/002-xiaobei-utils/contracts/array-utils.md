## Scope

本契约仅覆盖 `User Story 3 - 数组工具 (Priority: P3)`，包括：

- `unique(arr)`
- `sort(arr)`
- `filter(arr, fn)`

不覆盖字符串工具、数字工具或额外数组能力。

## Public Capabilities

### unique

**Purpose**: 移除数组中的重复元素。

**Input**:

- `arr`: 待去重数组。

**Output**:

- 返回数组。
- 结果仅包含唯一元素。
- 保留首次出现的元素顺序。
- 不修改输入数组。

**Examples**:

- 输入：`[1, 1, 2, 3]` → 输出：`[1, 2, 3]`
- 输入：`['a', 'a', 'b']` → 输出：`['a', 'b']`
- 输入：`[]` → 输出：`[]`

### sort

**Purpose**: 按默认升序规则排列数组。

**Input**:

- `arr`: 待排序数组。

**Output**:

- 返回数组。
- 结果按默认升序规则排列。
- 不修改输入数组。

**Examples**:

- 输入：`[3, 1, 2]` → 输出：`[1, 2, 3]`
- 输入：`[1, 2, 3]` → 输出：`[1, 2, 3]`
- 输入：`[]` → 输出：`[]`

### filter

**Purpose**: 根据同步过滤条件筛选数组元素。

**Input**:

- `arr`: 待过滤数组。
- `fn`: 同步过滤条件函数。

**Output**:

- 返回数组。
- 结果仅包含满足过滤条件的元素。
- 不修改输入数组。

**Examples**:

- 输入：`[1, 2, 3]`，条件：大于 `1` → 输出：`[2, 3]`
- 输入：`[1, 2, 3]`，条件：大于 `5` → 输出：`[]`
- 输入：`[]`，任意条件 → 输出：`[]`

## Quality Requirements

- 三个函数必须具备完整类型声明。
- 三个函数必须保持单一职责。
- 三个函数不应引入副作用，不应修改输入数组。
- 本契约不包含单元测试交付要求。
- 不引入深度对象去重、复杂比较器、多字段排序、异步过滤、链式集合或流式处理能力。
